# 🚀 SupportFlow

A modern Help Desk & Ticket Management System built with **React**, **ASP.NET Core Web API**, **Entity Framework Core**, **SQL Server**, and **JWT Authentication**.

## ✨ Features

* 🔐 JWT Authentication
* 🛡️ Role-Based Access Control (RBAC)
* 👥 User & Role Management
* 🏢 Department Management
* 📂 Category Management
* 🎫 Ticket Creation & Assignment
* 💬 Ticket Replies
* 📎 File Attachments
* 📊 Dashboard & Statistics

## 🛠️ Tech Stack

**Frontend**

* React
* React Router
* Axios

**Backend**

* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* JWT Authentication

## 📁 Project Structure

```text
SupportFlow.Api/
supportflow-client/
```

## 🚀 Getting Started

### Backend

```bash
cd SupportFlow.Api
dotnet run
```

### Frontend

```bash
cd supportflow-client
npm install
npm run dev
```
